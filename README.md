# 電子看板カメラ v49-inapp-update

## 変更点

- 画面右上に現在のバージョンを表示
- 設定画面にも現在バージョンを表示
- 画面右上と設定画面に「更新」ボタンを追加
- 更新時に Service Worker とブラウザキャッシュを削除して再読み込み
- Service Worker のキャッシュ名を v49 に更新

## 使い方

GitHub Pagesへ反映後、画面右上のバージョン表示で現在版を確認できます。
古い表示が残る場合は「更新」ボタンを押してください。


## v49a-save-fix

撮影後に保存失敗する端末向けの修正版です。iOS/Safariでは保存安定性を優先して旧Canvas看板描画へ自動切替します。
