# 電子看板カメラ v65.12

## v65.1 内部整理
- `main` の v64 を維持したままレビュー枝で整理開始
- 巨大な `index.html` からCSSと主要JavaScriptを外出し
- IndexedDB保存失敗時に撮影・看板修正・写真取込を成功扱いしないよう修正
- Service Workerのキャッシュ対象へ新しいCSS/JSを追加
- UI、看板、命名規則、操作仕様は変更しない

## 主な変更
- 通常表示写真をダブルタップ／ダブルクリックで拡大表示
- 看板編集時の「採取」を「サンプリング」へ変更
- 調査は青、サンプリングは緑で表示
- 「看板編集」の横に現在の看板種類を表示
- 看板の行高さを調整
  - 件名 52
  - 採取場所 40
  - 採取箇所／部屋No. 34
  - 試料No. 34
  - 区分 30
  - 日付 40
- 試料No.の箇所番号は `1` を下限とし、`1 ↔ 1-① ↔ 1-②` のように増減
- サンプリング時の採取箇所を矢印で補助増減
- `101`、`第2ビル 101`、英字、方角などを簡易判定
- `1-2階` などの範囲はセットで `1-2 → 2-3 → 3-4` と増減
- 判定できない表記は看板編集から手入力
- 編集完了ボタン、設定ボタン再押下で閉じる動作を維持


## v61 統合修正版
- v56で確認済みの枝番採番、サムネスワイプ、区分固定、看板編集反映を維持
- 看板編集の各文字サイズに項目別リセットを追加（18/17/24/24/24）
- 案件選択を左上、枚数表示を小型化し、選択画像を上寄せ
- 選択画像は表示枠内で縦横比維持・全体表示
- サムネイルは左右スクロールのみ。上下スクロールとページ横移動を抑止


## v62 追加機能
- 起動時に「カメラを起動」「写真から看板を付ける」を選択
- カメラロール等から複数写真を選択可能
- 既存の看板編集UIを使って1枚ずつ連続編集
- 前の写真の看板内容を次の写真へ引き継ぎ
- 編集進捗を「1 / N」で表示
- 編集中の元写真をIndexedDBへ一時保持し、再起動時に再開/破棄を選択
- 全件完了後は一時元画像を破棄し、看板付き写真だけ写真一覧へ追加
- 読み込み写真も既存の命名ルールでファイル名を生成
- EXIF向きを考慮して画像を正規化
- 読み込み編集時に4箇所の看板位置と既存サイズ変更を利用可能

## v64 修正

  - サンプリング: 施工前 / 施工中 / 施工後

- 写真 + 看板の編集プレビューと保存時の描画ロジックは従来どおり共通化

## v63 修正

- 調査 / サンプリング切替を編集プレビューへ即時反映
- 看板位置4か所・看板サイズ変更をプレビューへ即時反映
- 読み込み写真の保存時もプレビューと同じ位置・サイズ比率で看板を合成

## v65.4 保存層分離
- IndexedDBの写真/読込セッション操作を `js/photo-store.js` へ分離
- `app.js` はUI・撮影フロー側の責務へ寄せる
- DB名/バージョン/ストア名/接続状態を保存層へ集約
- 既存の呼び出し名は薄い別名で維持し、挙動変更を抑制

## v65.5 写真ビュー分離
- 写真案件管理・プレビュー・サムネイル/一覧・選択・並び順を `js/photo-viewer.js` へ分離
- 保存/共有・削除・写真拡大・看板修正導線も写真ビュー側へ集約
- 撮影処理・看板描画本体は `app.js` に維持
- UIと操作仕様は変更なし

## v65.6 写真取込分離
- 既存写真の複数選択・取込開始を `js/photo-import.js` へ分離
- IndexedDB一時セッションの再開/破棄・進捗管理を同モジュールへ集約
- 1枚ずつの看板編集・保存・次写真への引継ぎを取込フローとして分離
- カメラ撮影と看板描画本体は `app.js` に維持
- UIと操作仕様は変更なし

## v65.7 カメラ撮影分離
- カメラ起動/停止/プレビュー復帰を `js/camera.js` へ分離
- 断面モード、撮影、撮影直後確認、静止表示、画像生成を同モジュールへ集約
- 看板描画ルール本体 `drawBoardOnCanvas()` は `app.js` に維持
- UI・撮影仕様・ファイル名規則は変更なし

## v65.8 看板処理分離
- 看板初期化、入力、調査/サンプリング切替、採取箇所操作を `js/board.js` へ分離
- 看板位置/サイズ、編集、Undo/Redo、Canvas描画を同モジュールへ集約
- 共有状態は `app.js` に残し、既存モジュールとの挙動を維持
- UI・看板デザイン・撮影仕様は変更なし

## v65.9 設定処理分離

- 初期設定読込のため `settings.js` を `app.js` より先に読込

## v65.10 共通写真処理整理
