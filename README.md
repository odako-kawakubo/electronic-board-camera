# 電子看板カメラ v55

## v55 修正内容
- 看板編集で変更した項目別文字サイズを、撮影画像と看板修正後画像へ反映
- 撮影ボタン押下時の区分を固定し、断面撮影が直前区分になる問題を修正
- 写真名を `1-1-1.jpg`、2枚目以降を `1-1-1_02.jpg`、`1-1-1_03.jpg` と採番
- 看板修正後に、試料No.・箇所・区分から写真名を再生成
- 選択中画像とサムネイルを切り抜かず全体表示
- 下部サムネイルの横スワイプを改善し、スワイプ中の誤選択を抑制
- iPad／iPhoneのソフトウェアキーボード表示時に編集画面高を追従し、入力欄を自動で見える位置へ移動

## 主な変更
- 通常表示写真をダブルタップ／ダブルクリックで拡大表示
- 看板編集時の「採取」を「サンプリング」へ変更
- 調査は青、サンプリングは緑で表示
- 「看板編集」の横に現在の看板種類を表示
- 看板の行高さを調整
  - 件名 52
  - 採取場所 40
  - 採取箇所／部屋No. 34
  - 試料No. 34
  - 区分 30
  - 日付 40
- 試料No.の箇所番号は `1` を下限とし、`1 ↔ 1-① ↔ 1-②` のように増減
- サンプリング時の採取箇所を矢印で補助増減
- `101`、`第2ビル 101`、英字、方角などを簡易判定
- `1-2階` などの範囲はセットで `1-2 → 2-3 → 3-4` と増減
- 判定できない表記は看板編集から手入力
- 編集完了ボタン、設定ボタン再押下で閉じる動作を維持
