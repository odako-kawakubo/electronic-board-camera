# v65.12 残構造監査
## 結論
機能関数の分割は進んでいるが、`app.js` には共有DOM参照・共有状態・共通定数が残る。classic scriptの共有スコープを使っているため、担当が明確に見えても単純移動は危険。v65.12では依存関係を可視化し、安全な整形だけ実施した。
## 今回実際に整理したもの
- `setupBoardEditForm()` のインデントずれを修正。
- 主要JSDocの余分な空行を整理。
- `app.js` を「共通定数 / 共有DOM / 共有状態 / 起動イベント」に区画化。
## 監査で分かったこと
- `samplingLocationInput` は `null` 固定だが、宣言以外にも参照があるため削除しない。名前だけで未使用と判断しない。
- カメラ・ビューア・取込・看板の状態は担当モジュールが明確でも相互参照がある。
- `APP_DATA` の件名・住所は現在テスト用初期値。OneDrive/SharePoint案件連携時の置換対象。

## 次の整理候補
1. 単一機能へ移動候補は、呼出元を確認して1つずつ移す。
2. 複数モジュール共有状態は `AppState` 等の明示的な共有窓口を設計してから整理する。
3. `APP_DATA` は案件連携実装時に固定値から案件データへ置換する。
4. CSSの歴史的override層は別工程で所有関係を確認してから整理する。
