# v65.13 モジュール所有整理

## 目的
app.jsに残っていた宣言のうち、利用先が単一機能に限定されるものだけ担当モジュールへ移す。機能変更はしない。

## 移動先
- settings.js: APP_VERSION、設定用localStorageキー、設定画面DOM
- photo-utils.js: DEFAULT_POINT_NO
- photo-import.js: 取込DOMと取込セッション状態
- photo-viewer.js: ビューア専用DOMとビューア状態
- camera.js: カメラ専用DOMと撮影確認状態
- board.js: 看板専用DOM、localStorageキー、編集履歴/描画状態

## app.jsに残す共有状態
currentStream、capturedPhotos、previewIndex、selectedStatus、isSectionMode、boardMode、看板入力DOMなど、複数モジュールから使うものは現状維持。将来は共有状態APIを設計してから扱う。

## 非変更
IndexedDB構造、Base64形式、OneDrive、UI/操作、Service Worker挙動。
