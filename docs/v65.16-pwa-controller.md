# v65.16 PWA責務分離

## 目的
圏外起動強化の前段として、PWA固有処理を `pwa-controller.js` に集約する。

## pwa-controller.js の責務
- APP_VERSIONの正本
- バージョン表示・更新確認・手動更新
- Service Worker登録/解除
- Cache Storage削除
- iPhone/iPadホーム画面PWAのvisibility/pageshow復帰

## 境界
- IndexedDB写真データはPWA更新処理から削除しない。
- settings.jsはユーザー設定だけ。
- app.jsは機能初期化と共通UIだけ。
- service-worker.jsはオフラインキャッシュ本体。

## 次段階
`pwa-controller.js` と `service-worker.js` を中心に、完全圏外での起動・更新世代不一致・キャッシュ整合性を監査する。
