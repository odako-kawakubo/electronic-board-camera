# v65.19 端末保存診断・read-back確認

## 実機症状
撮影後に「撮影データの保存に失敗しました」と表示され、アプリ再起動後に写真が残らないことを確認。

## この版の目的
保存形式を変更せず、IndexedDB書込失敗の実体をiPhone実機で確認できるようにする。

## 変更
1. PhotoStore.savePhoto()はtransaction完了後に同じphotoIdを読み返す。
2. id / dataUrl / baseDataUrl の実在を確認する。
3. 保存失敗時は error.name / error.message / dataUrl+baseDataUrl概算サイズを返す。
4. camera.jsは診断情報を画面に表示し、成功確認前はcapturedPhotosへ追加しない。

## 変更しないもの
- IndexedDB `electronic-board-camera-prototype` version 2
- `photos` / `importSessions` store
- Base64保存形式
- 解像度・JPEG品質
- ファイル名規則
