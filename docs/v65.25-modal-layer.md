# v65.25 トップモーダル階層修正

## 原因
`launchModeOverlay` は `appOrientationShell` の外、`settingsOverlay` と `casePickerOverlay` はshell内にあった。
縦向き時のshellは `transform: rotate(...)` により独立したstacking contextを作るため、子のz-indexを大きくしても外側のトップ画面を越えられなかった。

## 修正
- 設定・案件選択をbody直下へ移動。
- トップ起点では無回転。
- アルバム起点では `app-oriented-modal` を付け、shellと同じ回転を適用。
- z-index値をさらに増やすだけの対症療法は行わない。
