# v65.26 写真レコード生成一本化

写真レコードのプロパティ構造は変更せず、生成責務だけを `photo-record.js` へ集約した。

- カメラ撮影: 元画像 `baseDataUrl` を保持。
- 看板添付: 元画像は保持せず、既存の `source: "import"` を維持。
- `caseId` / `caseDate` / `caseBranch` / `deviceName` / `oneDriveFolderName` は撮影・保存時点のCaseSessionから生成。
- `uploadStatus` 等の既存同期初期値もPhotoRecordで生成。
- 保存は従来どおりPhotoStoreが担当。
