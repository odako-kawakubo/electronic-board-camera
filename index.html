操作方法
確認したい項目を選んでください。

まず使う

1案件選択で対象案件を選びます。
2カメラ起動を押します。
3看板の案件名・住所・部屋No.・試料No.を確認して撮影します。
4ライト対応端末では、撮影中の映像上半分をダブルタップするとライトをON/OFFできます。
5写真一覧の●が緑になればOneDrive保存完了です。
Microsoft / OneDriveが未接続の場合は、トップ画面の「再接続」を押してください。

案件

案件選択

トップ画面の案件選択を押し、案件番号または案件名で検索して選択します。

OneDriveの正式案件と、この端末で作成した案件が表示されます。

新規案件

正式案件がまだない場合などは、新規案件から仮案件を作成して撮影できます。

案件を切り替えると、看板内容と写真一覧も選択した案件へ切り替わります。

撮影

調査 / サンプリング

撮影する内容に合わせてモードを切り替えます。

部屋

調査では階・部屋No.、サンプリングでは採取箇所を変更できます。

検体

試料No.・箇所No.を上下ボタンまたは中央ボタンから変更できます。

看板

看板のサイズや位置を調整できます。看板をダブルタップすると詳細編集を開きます。

看板

看板編集では、案件名、住所、部屋No./採取箇所、試料No.、日付、写真区分、看板種類を変更できます。

変更したい項目を選び、A- / A+で文字サイズを調整できます。

編集が終わったら右側の完了を押します。

看板編集画面の↶ / ↷は編集内容の「戻る / 進む」です。

写真

写真確認

写真一覧から撮影した写真を確認できます。写真をタップすると大きく表示できます。

看板修正

撮影済み写真を選び、元画像を使って看板だけ修正できます。

看板添付

トップ画面の看板添付から「既存看板」または「フリー看板」を選び、端末内の写真へ1枚ずつ看板を付けて保存できます。

既存看板は案件を選択すると案件名と住所を読み込み、その案件へ保存します。フリー看板は新規案件と同じ保存先を使用します。

途中で閉じても、未完了の編集はトップ画面から再開できます。

端末から写真を削除しても、OneDriveへ保存済みの写真は削除されません。

保存・再送

赤のままの場合

トップまたは設定の再接続を押します。それでも残る場合は、設定の今すぐ再送を押してください。

圏外で使う場合

圏外でも撮影と端末保存は続けられます。通信が戻るとOneDrive送信を再確認します。

緑になる前の写真は端末から削除しないでください。

設定・更新

端末名

設定からこの端末の名前を変更できます。

写真画質

標準 / 高画質を選択できます。

アプリ更新

設定 → バージョン確認から最新版を確認して更新します。

アプリを更新しても、案件・看板・端末内写真は削除されません。
